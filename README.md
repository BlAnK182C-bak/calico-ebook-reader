# Welcome to Calico!
Calico is an ebook reader TUI app built with [Rust](https://rust-lang.org/) and [Ratatui](https://ratatui.rs/).

This project aims to be a modern open source alternative to a lot of ebook readers which seem to limit the reader in some way shape or form.

## Releases and current features
You can go to the [releases](https://github.com/BlAnK182C-bak/calico-ebook-reader/releases/) tab for the latest canary build of this CLI tool.

Current features are:
* TUI Mode accessible from termimal emulators like Ghostty, Alacritty etc.
* Support for MacOS, Linux and Windows
* Support for parsing and reading of epub files

## Planned Features

With planned features such as:
- Support for PDF, MOBI, TXT and other formats
- Cross platform support across Android, iOS, MacOS, Windows and Linux
- Cross platform progress sync: have the option to sync your app across multiple platforms so you can continue reading ebooks no matter where you are.
- A plugin system allowing users creative freedom and control over the app
- Dictionary plug and play via APIs
- Hardcover integration for tracking books on [hardcover.app](https://hardcover.app/) - (If goodreads ever decides to actually make a public API again I am more than willing to add this integration too.)

and more planned...
